# SHORE design: "Harbor board" (round 3; replaces "Ferry log")

Art direction: harbor signage over shore sand. The page is a departures board for one crossing: a condensed signage face carries every number that matters, and one owned device, the tide band, shows ZEC moving from Solana (sea blue) to shielded Zcash (Zcash gold). The wordmark carries the same band.

- Type: Big Shoulders Display 600/800 (Chicago harbor signage; condensed tabular numerals for balance, quote, clock, landed amount, ledger rows) and Atkinson Hyperlegible 400/700 for reading (made for low-vision legibility). No serif, no mono.
- Colour, each with one job: sand #F2ECDF ground, deep-water ink #13233A text and primary buttons, sea blue #1E5A8A for the tide in transit and the active step, Zcash gold #F4B728 (text #6B4F00) only for shielded, warning red #A3341B for cost and "anyone can read".
- Signature: 10px tide band, revealed with clip-path against the clock, gold over the last third; landed amount sits on a gold underline; wordmark = 28x8 band + SHORE.
- Steps: no numerals; a 3px sea bar marks the active step, finished steps settle into one-line receipts with Change links.
- Radius 4px. Spacing 4/8/12/16/24/32/48/64/96. Motion: load rise once, receipts settle 200ms, tide reveal 400ms linear, landed count-up 450ms; all off under reduced motion.
- Refuse: serif + sans + sage + teal kit, circled stepper numerals, cards in cards, repeated numbers, uppercase micro-labels.
